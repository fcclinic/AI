|---|---|---|---|
| [AI] 저장 기능이 없습니다. | 새로고침 시 모든 배치가 초기화됨 | 반영 | 기획서의 "같은 파일을 다시 열어도 영화와 등급이 남습니다"라는 약속에 맞음 |
| [AI] '처음으로'가 직접 추가한 영화를 지우지 않습니다. | '처음으로' 클릭 시 새로 추가한 영화가 지워짐 | 보류 | 직접 해 보니 아님 (AI가 코드를 잘못 파악함) |
| [AI] 빈 제목을 막지 않아 기획서를 어깁니다. | 아무것도 입력하지 않고 추가 시 빈 카드가 생성됨 | 반영 | 기획서에 명시되진 않았으나 정상적인 사용을 위해 필요함 |
| [동료] 휴대폰으로 열어 보니까 좀 불편했어요. | 화면 폭을 줄이면 오른쪽이 잘려서 안 보임 | 반영 | 기획서의 "화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다"라는 약속에 맞음 |
| [동료] 카드 옮기는 게 처음엔 좀 헷갈렸어요. | 클릭 방식과 드래그 방식 모두 잘 작동함 | 되묻기 | 구체적으로 어떤 조작 방식(클릭 vs 드래그)이 헷갈렸는지 알 수 없어 확인 필요 |
| [동료] 안 정한 영화가 맨 아래에 있어 끌어 올리기 불편함. 목록을 위나 옆으로 변경 제안 | 스크롤이 길어지면 드래그가 불편하긴 함 | 보류 | 기획서의 "위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다."라는 조건과 부딪힘 |
| [동료] 카드 색이 좀 칙칙한 느낌? | 현재 색상도 가독성이 좋고 깔끔함 | 보류 | 취향이라 꼭 바꿀 이유가 없음 |
| [동료] 영화 포스터 사진이 같이 나오면 좋겠음 | 포스터 이미지를 넣으려면 외부 이미지 링크나 파일이 필요함 | 보류 | 기획서의 "외부 파일이나 로그인 없이 HTML 한 장으로 열립니다."라는 조건과 부딪힘 |
| [동료] C칸은 굳이 없어도 될 것 같음 | C칸이 정상적으로 존재함 | 보류 | 기획서의 "S·A·B·C 등급으로 나누어"라는 조건과 부딪힘 |

- 아무도 말하지 않았는데 내가 찾은 것: 이미 추가된 영화와 똑같은 이름의 영화를 중복해서 계속 추가할 수 있습니다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: AI가 코드를 분석할 때, 실제 동작과 다르게 파악하는 경우(예: '처음으로' 버튼 동작)가 있었습니다. AI의 코드 분석 결과를 어디까지 신뢰하고 어떻게 검증하는 것이 좋을지 이야기해 보고 싶습니다.
