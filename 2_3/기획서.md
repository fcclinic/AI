# 매장 손익분기점 계산기 기획서

## 대상 사용자

- 오프라인 매장(음식점, 카페, 소매점 등)을 운영하는 소상공인 및 자영업자
- 창업을 준비하며 예상 매출과 비용을 바탕으로 손익분기점을 검토하려는 예비 창업자

## 사용 목적

- 월별 매출액, 고정비, 변동비를 입력하여 매장의 손익 상태(흑자/적자)와 손익분기점(BEP) 매출액을 간편하게 확인합니다.
- 목표 영업이익을 달성하기 위해 필요한 월 및 일평균 필요 매출액을 역산하여 시뮬레이션합니다.

## 화면 구성과 동작

- **상단 안내 영역**: 부가가치세 제외(공급가액) 기준 입력 안내 공지 배너 제공
- **1. 기본 및 매출 정보 카드**: 
  - 분석 대상 월 선택(`input[type="month"]`), 월 실제 매출액 및 실제 영업일수 입력 폼
  - [저장된 값 불러오기] 버튼: 로컬 스토리지에 저장된 최근 입력값 불러오기 (컴팩트한 버튼 형태로 정돈)
- **2. 고정비 입력 카드**: 
  - 임대료, 직원 고정급여, 관리비, **수도광열비(신규 추가)**, 통신비·인터넷비, 보험료, 정기 구독료, 기타 고정비 입력 폼 및 하단 고정비 합계 실시간 산출
- **3. 변동비 입력 카드**: 
  - 식재료비·상품 매입원가, 포장재·일회용품비, 카드 및 간편결제 수수료, 배달 플랫폼 수수료, 매출 연동 인건비, 기타 변동비 입력 폼 및 변동비율 실시간 미리보기, 하단 변동비 합계 산출
- **하단 제어 버튼**: [손익분기점 계산하기] 및 [초기화] 버튼
- **📊 손익분기점 분석 결과 영역 (계산 후 활성화)**: 
  - 흑자/적자 상태 뱃지 및 상세 분석 설명문
  - 주요 지표 그리드 (실제 매출, 고정비, 변동비, 변동비율 및 공헌이익률, BEP 매출액, 추정 영업손익, 실제 일평균 매출, BEP 일평균 매출)
  - 🎯 목표 영업이익 달성 시뮬레이션 (목표 영업이익 입력 시 필요 월/일 매출 자동 역산)
  - 인쇄 및 PDF 저장 버튼, 경영 관리용 추정치 유의사항 안내

## 필요한 자료

- 사업장의 월별 실제 매출액(공급가액 기준)
- 고정비 내역 (임대료, 인건비, 관리비, 수도광열비, 보험료 등 매월 정기 지출 항목)
- 변동비 내역 (식재료 원가, 수수료, 소모품비 등 매출 연동 지출 항목)

## 완료 기준

- [x] 월 매출액, 고정비, 변동비, 영업일수를 입력하고 계산 버튼을 눌렀을 때 손익분기점 매출액과 추정 영업손익이 정확한 산식에 따라 출력됩니다.
- [x] 매출액이 0원이거나 변동비가 매출액 이상일 때, 계산이 차단되며 명확한 예외 안내 메시지가 표시됩니다.
- [x] 다른 파일, 서버 로그인, 외부 API 키 없이 HTML 파일 하나(CSS 및 JS 내장)로 브라우저에서 즉시 정상 동작합니다.

## 추가 기능

- 입력한 계산 데이터의 브라우저 로컬 스토리지 자동 백그라운드 저장 및 불러오기 기능
- 브라우저 인쇄(`window.print()`)를 통한 결과 리포트 PDF 출력 기능

## 한계 및 비목표

1. 본 계산기는 부가가치세가 제외된 공급가액을 기준으로 산출되는 경영 관리용 추정치이며, 실제 회계상 소득세·법인세, 금융이자 및 감가상각비는 반영되지 않습니다.
2. 기말 재고 변동이나 외상 매출·미지급금 등 회계적 발생주의 요소는 실무 편의를 위해 제외하였습니다.
3. 실시간 서버 연동이나 사용자 계정별 데이터베이스 저장 기능은 제공하지 않으며, 클라이언트 로컬 스토리지를 활용합니다.

## 검증 방법

- 계산기 결과로 산출된 손익분기점 매출액 및 공헌이익률을 기획서 검증 공식($\text{BEP 매출액} = \frac{\text{고정비 합계}}{1 - \frac{\text{변동비 합계}}{\text{실제 매출액}}}$)에 직접 대입하여 계산한 수치와 대조하여 일치 여부를 검증합니다.
