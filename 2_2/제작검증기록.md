# 제작·검증 기록: 나만의 여행 일정 관리 페이지

## 두 AI 비교
- AI A (서비스·모델 이름): Claude
- AI B (서비스·모델 이름): ChatGPT
- 동일한 기획서와 함께 전달한 요청: 여행 일정 관리 HTML 페이지 제작을 위한 기획서 전달 및 코드 생성 요청

| 테스트 내용 | AI A (Claude) | AI B (ChatGPT) |
| --- | --- | --- |
| 디자인 및 UI 세련도 | 기본적이고 무난한 수준 | 시각적으로 더 세련되고 완성도 높음 |
| 정보 구성 및 항목 배치 | 일반적인 정보 나열 | 여행 일정 관리에 최적화된 우수한 배치 |
| 반응형 웹(창 크기 조절) 구현 | 휴대폰 최적화 | 정상 작동 |

- 선택한 결과물과 근거: **AI B (ChatGPT)**. 두 AI에게 동일한 기획서를 전달하여 비교한 결과, ChatGPT가 생성한 결과물이 디자인(UI) 측면에서 더 세련되었으며, 여행 일정 관리에 필요한 정보 구성과 항목 배치가 더 우수하여 최종 코드로 선택함.

## 테스트 기록
| 번호 | 테스트 내용 | 예상 결과 | 실제 결과 |
| --- | --- | --- | --- |
| 1 | 브라우저 창 크기 조절 테스트 (반응형) | 창 크기에 맞춰 레이아웃이 깨지지 않고 자연스럽게 조절될 것이다. | 완벽하게 작동함 (성공) |
| 2 | 브라우저 상에서 텍스트 입력/수정 및 일정 추가 | 텍스트를 클릭하면 내용이 수정되고, 버튼을 누르면 일정이 추가될 것이다. | 텍스트 수정 불가, 일정 추가 버튼 미작동 (실패) |
| 3 (구글맵 링크 클릭 시 특정 식당명 검색 여부) | 새 창이 열리며 기획한 특정 식당명(장소)이 구글맵에서 바로 검색될 것이다. | 새 창은 열리나 특정 식당명이 검색되지 않고 일반 검색창이 뜸 (실패) |

## 수정 기록

### 수정 기록 1
- 발견한 문제: 브라우저 화면에서 여행 정보나 일정 텍스트를 클릭해도 입력 및 수정이 불가능함 (테스트 2 실패).
- AI에게 전달한 요청: HTML 화면에서 글자를 클릭했을 때 메모장처럼 직접 텍스트를 수정할 수 있게 만들어줘. (contenteditable 속성 추가)
- 수정 후 테스트 결과: 텍스트 클릭 시 커서가 활성화되며 정상적으로 내용 입력 및 수정이 가능해짐.
- 수정 이유: 기획서의 핵심 요구사항인 '브라우저 상에서 사용자가 자신의 여행 일정으로 직접 내용을 수정하는 기능'을 구현하기 위함.

### 수정 기록 2
- 발견한 문제: 바우처 및 지도 링크 클릭 시, 구글맵에서 특정 장소가 검색되지 않고 구글 일반 검색 결과가 나옴 (테스트 3 실패).
- AI에게 전달한 요청: a 태그의 링크를 클릭했을 때, 구글 일반 검색이 아니라 구글맵에서 특정 장소(예: 식당 이름)가 바로 검색되도록 URL 형식을 수정해줘.
- 수정 후 테스트 결과: 링크 클릭 시 구글맵 새 창이 열리며 지정해 둔 특정 장소가 정확하게 검색됨.
- 수정 이유: 사용자가 여행지에서 필요한 장소의 지도를 헤매지 않고 즉각적으로 확인하여 편의성을 높이기 위함.

### 수정 기록 3
- 발견한 문제: '일정 추가' 버튼을 눌러도 새로운 일정이 화면에 추가되지 않음 (테스트 2 실패).
- AI에게 전달한 요청: 일정 추가 버튼을 클릭하면 새로운 일정 칸이 화면에 나타나도록 JavaScript 코드를 추가/수정해줘.
- 수정 후 테스트 결과: 버튼 클릭 시 새로운 일정 항목이 정상적으로 화면에 추가됨.
- 수정 이유: 여행 일정이 길어지거나 방문 장소가 많을 경우, 사용자가 자유롭게 일정을 확장하고 관리할 수 있도록 하기 위함.

## 사용자 테스트
- 테스트 참여자와 요청한 작업: 지인에게 해당 HTML 파일을 열어보고, 본인의 가상 여행 일정을 직접 입력해 보라고 요청함.
- 사용자의 행동과 질문: 텍스트를 클릭해 여행지와 날짜를 입력해 봄. "항공권 바우처 링크는 내 실제 예약 주소로 어떻게 바꿔?"라고 질문함.
- 받은 피드백: 화면이 깔끔해서 보기 좋고, 바로바로 글씨를 수정할 수 있어서 편하다. 다만 처음 쓰는 사람을 위해 어디를 수정해야 하는지 안내 문구가 있으면 좋겠다.
- 반영 내용과 결과: 사용자가 쉽게 수정할 수 있도록 기본 텍스트를 "이곳을 클릭해 내용을 입력하세요"와 같이 직관적인 안내 문구로 변경하여 사용성을 개선함.
