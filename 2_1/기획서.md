# 매장 손익분기점 계산기

## 대상 사용자

-   현재 음식점, 카페, 소매점 등 오프라인 매장을 실제 운영하고 있는
    소상공인 및 자영업자
-   회계·재무 전문지식이 많지 않더라도 월별 매출과 비용을 입력하여
    매장의 손익 상태를 확인하고 싶은 운영자

## 사용 목적

-   특정 월의 실제 매출과 비용을 바탕으로 매장의 손익분기점 매출을
    계산한다.
-   해당 월의 실제 매출이 손익분기점보다 높은지 낮은지 확인하여
    흑자·적자 상태를 파악한다.
-   손익분기점까지 필요한 매출 차이와 하루 평균 매출 기준을 확인하여
    다음 달의 매출 목표를 세우는 데 참고한다.
-   고정비와 변동비의 구성 및 비율을 확인하여 비용 관리와 경영 개선의
    기초자료로 활용한다.

## 화면 구성과 동작

### 1. 기본 화면

-   페이지 상단에 `매장 손익분기점 계산기` 제목과 간단한 사용 안내를
    표시한다.
-   분석 대상 월을 선택하는 입력란을 제공한다. 예: 2026년 10월.
-   입력 화면은 `매출 정보`, `고정비`, `변동비` 영역으로 구분한다.
-   각 비용 항목 옆에는 간단한 설명 또는 입력 예시를 제공한다.
-   금액은 원 단위의 숫자로 입력하며, 입력값과 계산 결과는 천 단위
    쉼표를 적용해 읽기 쉽게 표시한다.
-   비용이 발생하지 않은 항목은 0원으로 입력할 수 있으며, 모든 비용
    항목을 반드시 채우도록 강제하지 않는다.

### 2. 매출 정보 입력

-   분석 대상 월의 실제 매출액을 입력한다.
-   해당 월의 실제 영업일수를 입력한다.
-   매출액은 해당 월의 전체 영업 매출을 기준으로 입력한다. 부가가치세를
    제외한 공급가액 기준으로 매출과 비용을 일관되게 입력하도록 안내한다.
-   영업일수는 해당 월에 실제 영업한 날짜 수를 입력한다. 휴무일은
    제외한다.

### 3. 고정비 입력

-   매출액이나 판매량이 달라져도 해당 월에 대체로 일정하게 발생하는
    비용을 입력한다.
-   기본 항목은 다음과 같다.
    -   임대료
    -   직원 고정급여
    -   관리비
    -   통신비·인터넷비
    -   보험료
    -   정기 구독료 및 기타 정기 비용
    -   기타 고정비
-   각 항목은 해당 분석 월에 귀속되는 금액을 입력한다.
-   해당하지 않는 항목은 0원으로 입력한다.
-   고정비 합계는 입력값을 바탕으로 자동 계산하여 표시한다.

### 4. 변동비 입력

-   매출이나 판매량에 따라 함께 증가하거나 감소하는 비용을 해당 월
    기준으로 입력한다.
-   기본 항목은 다음과 같다.
    -   식재료비·상품 매입원가
    -   포장재·일회용품 등 판매 관련 소모품비
    -   카드 및 간편결제 수수료
    -   배달 플랫폼 수수료
    -   매출·판매량에 연동되는 인건비
    -   기타 변동비
-   식재료비·상품 매입원가는 단순히 해당 월에 결제한 매입액이 아니라,
    가능한 경우 해당 월에 실제 판매되어 사용된 재고의 원가를 입력하도록
    안내한다. 재고 매입액만 알고 있는 경우에는 그 금액을 사용했음을
    유의사항으로 안내한다.
-   직원 급여는 매출과 관계없이 정기적으로 지급하는 금액은 고정비에,
    매출이나 판매량에 따라 달라지는 금액은 변동비에 입력하도록 안내한다.
-   각 항목은 해당 분석 월에 귀속되는 금액을 입력한다. 해당하지 않는
    항목은 0원으로 입력한다.
-   변동비 합계와 매출액 대비 변동비율은 자동 계산하여 표시한다.

### 5. 계산 및 결과 화면

-   `손익분기점 계산하기` 버튼을 누르면 입력값을 바탕으로 계산한다.
-   결과 영역에는 다음 내용을 표시한다.
    -   월 실제 매출액
    -   월 고정비 합계
    -   월 변동비 합계
    -   변동비율
    -   손익분기점 매출액
    -   실제 매출과 손익분기점의 차이
    -   추정 영업손익
    -   실제 일평균 매출
    -   손익분기점 달성을 위한 일평균 매출
-   실제 매출이 손익분기점보다 높으면 `손익분기점 초과` 또는
    `흑자 추정`으로 표시하고, 낮으면 `손익분기점 미달` 또는
    `적자 추정`으로 표시한다.
-   손익분기점까지 필요한 매출액 또는 초과한 매출액을 금액으로 함께
    표시한다.
-   결과는 숫자만 나열하지 않고 각 지표의 의미를 짧고 쉬운 문장으로
    설명한다.
-   `다시 계산하기` 또는 입력값 수정 후 재계산할 수 있도록 한다.
-   `초기화` 버튼을 제공하여 입력값과 계산 결과를 모두 지울 수 있다.
    초기화 전에는 실수로 입력값을 지우지 않도록 확인 안내를 표시한다.

### 6. 계산 기준 및 산식

-   변동비율 = 해당 월 변동비 합계 ÷ 해당 월 매출액
-   공헌이익률 = 1 - 변동비율
-   월 손익분기점 매출액 = 해당 월 고정비 합계 ÷ 공헌이익률
-   추정 영업손익 = 실제 매출액 - 변동비 합계 - 고정비 합계
-   실제 일평균 매출 = 실제 매출액 ÷ 실제 영업일수
-   손익분기점 달성을 위한 일평균 매출 = 월 손익분기점 매출액 ÷ 실제
    영업일수
-   손익분기점 초과·미달 매출 = 실제 매출액 - 월 손익분기점 매출액

위 산식은 입력한 매출과 비용의 기간 및 세금 기준이 서로 일치한다는
전제에서 사용한다. 결과는 입력한 비용 항목을 기준으로 한 관리용
추정치이며, 세금·이자·감가상각 등 입력하지 않은 비용이나 회계상 조정에
따라 실제 회계 손익과 다를 수 있음을 표시한다.

### 7. 입력값 검증 및 예외 처리

-   매출액, 비용, 영업일수에는 음수를 입력할 수 없도록 한다.
-   금액란에는 숫자만 입력할 수 있도록 하고, 비정상적인 문자 입력은
    안내한다.
-   분석 대상 월, 실제 매출액, 영업일수는 필수 입력으로 한다.
-   영업일수는 1일 이상이어야 한다.
-   실제 매출액이 0원이면 변동비율과 손익분기점 매출액을 계산할 수
    없다는 안내를 표시한다.
-   변동비 합계가 매출액 이상이면 공헌이익이 0 이하이므로 일반적인
    손익분기점 매출액을 산출할 수 없다는 안내를 표시한다. 이 경우 임의의
    손익분기점 숫자를 표시하지 않는다.
-   필수 입력값이 누락되거나 잘못된 경우 계산을 진행하지 않고, 어느
    항목을 수정해야 하는지 해당 입력란 근처에 안내한다.
-   비용 항목을 모두 입력하지 않아도 계산할 수 있도록 하되, 입력하지
    않은 비용은 0원으로 간주된다는 점을 안내한다.

## 필요한 자료

-   별도 외부 자료나 API는 필요하지 않다.
-   사용자가 직접 입력할 자료:
    -   분석 대상 월
    -   해당 월의 실제 매출액
    -   해당 월의 실제 영업일수
    -   해당 월에 귀속되는 고정비 항목별 금액
    -   해당 월에 귀속되는 변동비 항목별 금액
-   입력 안내를 위한 비용 항목 설명과 계산 산식
-   금액 표시를 위한 원화(원) 단위 및 천 단위 구분 형식
-   외부 이미지, 웹폰트, 외부 라이브러리 없이 기본 HTML·CSS·JavaScript로
    구현한다.

## 완료 기준

-   분석 대상 월, 실제 매출액, 실제 영업일수와 비용 항목을 입력할 수
    있다.
-   고정비와 변동비가 서로 구분되어 표시되고, 각 항목의 합계가 입력값에
    맞게 자동 계산된다.
-   변동비 합계를 실제 매출액으로 나눈 변동비율이 정확하게 표시된다.
-   계산 버튼을 누르면 손익분기점 매출액, 실제 추정 영업손익, 실제
    매출과 손익분기점의 차이 및 일평균 매출 관련 지표가 표시된다.
-   실제 매출이 손익분기점보다 높을 때와 낮을 때 결과 문구 및 상태
    표시가 각각 올바르게 바뀐다.
-   입력값을 수정하고 다시 계산하면 수정된 값이 결과에 반영된다.
-   비용 항목을 0원으로 입력하거나 비워 둔 경우에도 안내된 기준에 따라
    계산할 수 있다.
-   매출액이 0원이거나 변동비 합계가 매출액 이상인 경우, 계산할 수 없는
    이유를 알기 쉽게 안내하고 잘못된 손익분기점 수치를 표시하지 않는다.
-   음수, 문자 등 잘못된 입력값이나 필수 입력 누락이 있으면 계산을
    중단하고 수정할 항목을 안내한다.
-   초기화 버튼을 누르면 입력값과 계산 결과가 초기 상태로 돌아간다.
-   금액은 원화 기준으로 읽기 쉽게 표시되고, 결과와 입력 항목의 명칭 및
    설명은 한국어로 제공된다.
-   PC와 스마트폰의 일반적인 브라우저 화면에서 입력·계산·초기화 기능을
    사용할 수 있도록 반응형으로 구성한다.
-   완성된 HTML 파일 하나에 HTML·CSS·JavaScript가 포함되어 있고, 별도
    파일 설치나 서버 실행, 로그인, API 키 없이 브라우저에서 직접 열어
    사용할 수 있다.

## 추가 기능

-   실제 월별 실적을 기준으로 매출액이나 비용을 변경했을 때 예상 손익이
    어떻게 달라지는지 확인하는 손익 시뮬레이션 기능
-   목표 영업이익을 입력하면 해당 이익을 달성하기 위해 필요한 월
    매출액과 일평균 매출을 역산하는 기능
-   입력값과 계산 결과를 인쇄하거나 PDF로 저장하는 기능
-   입력값을 브라우저에 저장하여 다음 방문 때 다시 불러오는 기능

## 한계 및 비목표

1.  본 페이지는 사용자가 입력한 한 달의 매출과 비용을 바탕으로
    손익분기점을 계산하는 관리용 도구이며, 회계·세무 신고나 전문적인
    재무제표 작성 기능을 제공하지 않는다.
2.  사용자가 입력하지 않은 비용, 세금, 이자, 감가상각, 재고 평가 차이
    등은 계산에 반영되지 않을 수 있다. 매출과 비용의 기간 및 부가가치세
    제외 기준을 일관되게 입력해야 하며, 결과는 실제 회계상 손익과 차이가
    날 수 있다.
3.  이번 구현에서는 회원가입·로그인, 서버 및 데이터베이스 연동, 여러
    매장의 통합 관리, 외부 POS·회계 프로그램 연동, 자동 데이터 수집
    기능을 구현하지 않는다. 월별 기록의 장기 저장 및 비교 분석도 필수
    범위에서 제외한다.

## 검증 방법

-   가상의 월 실적을 정해 계산 결과를 손으로 계산한 값과 웹페이지의
    결과를 비교한다.
-   예를 들어 월 매출 30,000,000원, 월 고정비 10,000,000원, 월 변동비
    10,500,000원, 영업일수 26일을 입력한다.
    -   변동비율은 10,500,000 ÷ 30,000,000 = 35%여야 한다.
    -   공헌이익률은 65%여야 한다.
    -   손익분기점 매출액은 10,000,000 ÷ 0.65 = 약 15,384,615원이어야
        한다.
    -   추정 영업손익은 30,000,000 - 10,500,000 - 10,000,000 =
        9,500,000원이어야 한다.
    -   실제 일평균 매출은 30,000,000 ÷ 26 = 약 1,153,846원이어야 한다.
    -   손익분기점 달성을 위한 일평균 매출은 약 15,384,615 ÷ 26 = 약
        591,716원이어야 한다.
-   위 값과 웹페이지 표시 결과를 비교하여 계산 정확성을 확인한다.
-   추가로 매출액 0원, 변동비가 매출액과 같거나 큰 경우, 음수 입력,
    필수값 누락, 초기화 동작을 각각 시험하여 예외 안내와 화면 동작이
    기획대로 작동하는지 확인한다.
