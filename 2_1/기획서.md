# 나만의 여행 일정 관리 페이지

## 대상 사용자

- 나 혼자 (작성자 본인) 및 일정을 공유받는 친구/지인

## 사용 목적

- 여행 전 계획(항공권, 숙소, 준비물)을 한눈에 정리하고, 여행 중 스마트폰으로 일정을 직관적으로 확인하기 위함.
- 완성된 HTML 파일 자체를 지인들에게 전달하여 간편하게 여행 일정을 공유하기 위함.

## 화면 구성과 동작

- **상단 (핵심 정보 및 준비물)**: 항공권/숙소 요약 정보란과 준비물 체크리스트가 있습니다. 체크박스를 누르면 완료(취소선 등) 표시가 됩니다.
- **중단 (일차별 탭)**: '1일차', '2일차' 등의 탭 버튼이 있습니다. 버튼을 누르면 화면 새로고침 없이 해당 일자의 일정표만 화면에 나타납니다.
- **하단 (일정표)**: 시간대별 방문 장소와 메모가 표시됩니다. 장소 이름을 누르면 새 창으로 해당 장소의 구글 맵 검색 결과가 열립니다. 예약 바우처 등의 기타 링크도 쉽게 누를 수 있게 배치됩니다.

## 필요한 자료

- 구글 맵 검색 자동 연결을 위한 URL 템플릿 (`https://www.google.com/maps/search/?api=1&query=장소명`)
- 외부 이미지 없이도 깔끔하게 보이도록 구성된 HTML/CSS UI 요소 (아이콘 대용 이모지 등 활용)

## 완료 기준

- 상단의 '1일차', '2일차' 탭 버튼을 클릭했을 때, 화면 새로고침 없이 해당 일자의 일정만 정확히 표시되어야 한다.
- 일정표의 '장소 이름'을 클릭했을 때, 새 창으로 구글 맵 검색 결과가 정상적으로 열려야 한다.
- 맥(Mac) 컴퓨터의 넓은 화면과 안드로이드 스마트폰의 좁은 화면에서 열었을 때, 내용이 잘리거나 깨지지 않고 기기 화면에 맞춰 레이아웃이 자동 변환(반응형 웹)되어야 한다.
- 서버, DB, 복잡한 설치 없이 **HTML 파일 단 하나**만으로 브라우저에서 열었을 때 모든 기능이 작동해야 한다.

## 추가 기능

- 여행 경비 단순 요약표 (추후 필요시 HTML에 표 형태로 추가)
- 다크 모드 지원 (추후 CSS로 확장 고려)

## 한계 및 비목표

1. **데이터 영구 저장 불가**: 서버나 DB를 사용하지 않으므로, 브라우저에서 체크박스를 누르거나 상태를 변경해도 새로고침하면 초기화됩니다. (내용 수정은 HTML 코드를 직접 수정해야 함)
2. **실시간 지도 화면 연동 제외**: 구글 맵 화면을 페이지 안에 직접 띄우지 않고, 외부 링크로 새 창에서 열리도록만 구현합니다.
3. **로그인 및 권한 관리 제외**: 누구나 파일을 열면 동일한 내용을 보게 되며, 별도의 회원가입이나 관리자 기능은 구현하지 않습니다.

## 검증 방법

- **구글 맵 링크 및 반응형 테스트**: 
  1. 페이지에서 임의의 장소 링크를 클릭했을 때, 열린 구글 맵 화면의 검색창에 해당 장소명이 정확히 입력되어 검색되는지 직접 클릭하여 확인합니다.
  2. PC 브라우저 창 크기를 마우스로 줄여보거나 실제 안드로이드 스마트폰에서 파일을 열어, 모바일 화면처럼 세로형으로 깔끔하게 배치되는지 눈으로 확인합니다.
