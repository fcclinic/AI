# 제작·검증 기록: 매장 손익분기점 계산기

## 두 AI 비교
- AI A (서비스·모델 이름): Google Gemini (Gemini 3.6 Flash)
- AI B (서비스·모델 이름): OpenAI ChatGPT (GPT-4o)
- 동일한 기획서와 함께 전달한 요청:
  > "다음 기획서를 바탕으로 html 파일을 만들어줘. 바로 복사할수 있는 원본 html이 필요해." (이어서 기획서 전문 전달)

| 테스트 내용 | AI A | AI B |
| --- | --- | --- |
| **코드 구조 및 실행 편의성** | 단일 파일(HTML+CSS+JS)로 구성되어 서버 없이 브라우저에서 즉시 실행 가능 | 단일 파일(HTML+CSS+JS)로 구성되어 서버 없이 브라우저에서 즉시 실행 가능 |
| **예외 처리 및 방어 로직** | 매출액 0원 및 변동비가 매출액 이상일 때 계산을 차단하고 명확한 경고/안내 메시지 출력 | 매출액 0원 또는 변동비 초과 시 일부 안내가 누락되거나 오류 처리 방식이 미흡함 |
| **UI/UX 및 부가 기능** | 반응형 카드 레이아웃과 천 단위 쉼표 자동 포맷팅, 목표 영업이익 역산 시뮬레이션 기능 구현 | 기본적인 입력 폼과 계산 결과는 구현되었으나 시뮬레이션 기능 및 세부 UI 정교함이 부족함 |

- 선택한 결과물과 근거:
  - **선택한 결과물:** AI A (Google Gemini 3.6 Flash)의 결과물
  - **선택 근거:** 기획서에 명시된 필수 예외 처리(매출액 0원 및 변동비 $\ge$ 매출액 조건)와 산식을 완벽하게 구현하였고, 입력 시 실시간 소계 계산, 천 단위 자동 쉼표 포맷팅, 그리고 목표 영업이익 역산 시뮬레이션 기능까지 UI/UX 완성도가 가장 뛰어남.

## 수정 기록

### 수정 기록 1
- 발견한 문제: 초기 입력 시 숫자가 입력되지 않은 빈 상태(공백)로 방치될 경우 천 단위 쉼표 포맷팅 함수에서 불필요한 예외 로그가 발생할 가능성 확인
- AI에게 전달한 요청: 숫자 입력 필드에 빈 값이 들어오거나 지워질 때 에러 없이 자연스럽게 0 또는 빈칸으로 처리되도록 입력 이벤트 핸들러 보완 요청
- 수정 후 테스트 결과: 백스페이스로 모든 숫자를 지워도 콘솔 오류 없이 안전하게 빈칸 및 0원으로 처리됨
- 수정 이유: 사용자 편의성과 안정적인 자바스크립트 실행을 보장하기 위함

### 수정 기록 2
- 발견한 문제: 영업일수에 실수나 음수(-1 등)가 입력될 경우 일평균 매출 산식에서 잘못된 계산 값이 반영될 위험성 확인
- AI에게 전달한 요청: 영업일수 입력란에 0 미만의 음수나 비정상적인 값이 들어오지 못하도록 유효성 검사 및 min/max 제한 추가 요청
- 수정 후 테스트 결과: 음수 입력 시 즉시 값이 비워지며 1일 미만 입력 시 오류 메시지가 정상 작동함
- 수정 이유: 일평균 매출 및 BEP 일매출 산식의 수학적 오류를 원천 차단하기 위함

### 수정 기록 3
- 발견한 문제: 모바일 화면에서 결과 카드의 수치 글자 크기가 다소 커서 일부 긴 금액(억 단위 이상)이 줄바꿈될 우려 확인
- AI에게 전달한 요청: 작은 화면(모바일) 환경에서 `metrics-grid` 내부 수치 폰트 크기와 패딩 여백을 유연하게 조절하도록 미디어쿼리 스타일 보완 요청
- 수정 후 테스트 결과: 화면 폭이 좁아져도 금액이 한 줄에 깔끔하게 표현되어 가독성이 대폭 향상됨
- 수정 이유: 다양한 디바이스 환경에서 시각적 완성도와 가독성을 높이기 위함

## 사용자 테스트
- 테스트 참여자와 요청한 작업: 오프라인 카페를 운영 중인 지인(매장 관리자)에게 프로그램 링크를 전달하고, 지난달 실제 정산 데이터를 직접 입력하여 손익분기점과 목표 영업이익 시뮬레이션을 실행해 보도록 요청함
- 사용자의 행동과 질문: "식재료비 원가를 계산할 때 기말재고를 빼야 하는지" 질문하였고, 곧바로 실제 매입금액 기준으로 입력한 뒤 계산 버튼을 눌러 흑자/적자 상태를 확인하고 목표 이익 역산 기능을 실행함
- 받은 피드백: "입력할 때 콤마(,)가 알아서 찍히니까 큰 금액을 적을 때 자릿수 헷갈릴 일이 없어 편하고, 일평균 매출 목표가 바로 눈에 들어와서 다음 달 계획 세우기에 실용적이다"라는 긍정적 피드백을 받음
- 반영 내용과 결과: 사용자가 실제 업무 환경에서 유용하게 쓸 수 있음을 확인하였으며, 안내 문구 중 공급가액 기준에 대한 설명이 직관적으로 다가간다는 점을 검증함
